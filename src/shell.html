    Each row moves by its own random number of days. Intervals within a row stay exact, such as age at appointment.

    Help

    Safest choice first

    Start with the safest choice. Move to the next level only when the AI truly needs it.

    1. Column names only. Share the column names, data types and one masked example. This is enough for an AI to write an Excel formula.
    2. A masked sample. Share 20 to 50 masked rows only when the AI must see how the data is typed, and only when your organisation's rules allow it.
    3. Totals by group. Count totals on your own computer, for example the number of staff in each grade. Share the totals only. Each group must hold at least 5 people.

    Never share the real data rows. Run the AI's formula or script on the real file on your own computer.

    Masking does not change how the file is classified

    Masking lowers the risk, but your organisation still classifies the file the same way. A masked extract of a restricted record is still restricted.

    Follow your organisation's rules before you share any data with an AI tool or anyone else.

    How to use it

    1. Open a CSV or Excel file. Choose the sheet and the header row, or tick “My file has no header row”.
    2. For each column, choose Mask, Remove or Keep. Each card shows how the values change. Open “Tidy and date options” to set the date order.
    3. Choose the rows to download and read the preview.
    4. Open Risk check. Fix every red warning and read free-text notes yourself.
    5. Download the column names or the masked data. Download the match file after the masked data, and keep it on this computer only.

    Supported formats

    The tool recognises common English column names and these value formats. Check every suggestion, because other formats can look like text.

    • Column names such as Name, ID or Employee ID, National ID or SSN, Date of Birth, Email, Phone, Address, Salary, and Notes.
    • National IDs written like 123-45-6789.
    • Phone numbers with a + sign, spaces, dashes or brackets, such as +44 20 7946 0958 or (415) 555-0100.
    • Dates as DD/MM/YYYY, MM/DD/YYYY, YYYY-MM-DD, or with an English month name, such as 25 Dec 2004 or December 25, 2004.
    • Money with a symbol or a currency code, such as $1,250.00 or EUR 900.50.
    • Addresses with a street word such as Street, Road or Avenue, or with a postcode.

    The match file and how to restore names

    The match file links each code to the real value. Codes of the type “Numbered” are dealt out in random order, so a number does not show a row position. Codes of the type “Random” are letters and digits. Both are safe. Codes ignore letter case, so “maria garcia” and “Maria Garcia” share one code.

    • Keep the match file on this computer only. Never upload it to an AI tool, email, Google Drive or OneDrive.
    • Never open and save the match file in Excel. Excel can change long numbers and drop leading zeros.
    • To restore names, open the Restore names tab. Open the match file, then paste the AI answer or open a CSV or Excel file.
    • Delete the match file when the work is done.

    Limits of this tool

    • The detected column types are suggestions only. You must check every column yourself.
    • Mask names in notes finds only names from the name columns, their first and last words, and ID, email and phone patterns. It misses nicknames, other spellings and other personal details.
    • A combination such as grade and unit can still show who someone is after the name is removed. Use the “Can someone be picked out?” check in Risk check, and merge groups of fewer than 5 people.
    • A date such as 03/04/2020 is read day first or month first, as set under Tidy and date options. Age groups use today's date.
    • Shifted dates are restored only in CSV or Excel files, not in pasted text. The file must keep the code column that the match file uses to line up rows, or the original row order.
    • Text that is not in UTF-8 can look garbled. Choose the right text encoding in step 1 and check a few values.
    • The tool reads English column names and English month names. For other languages, check every column yourself. Text in scripts without letter case, such as Chinese or Arabic, is flagged for you to check.
    • Excel formulas are not recalculated. The tool reads the values stored in the cells.
    • Large files are processed in the browser. A file of 20,000 rows × 40 columns takes a few seconds.
