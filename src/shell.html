    Help

    What this tool does

    It replaces personal data in a spreadsheet with codes, ranges or blanks. You can then share the copy.

    Everything happens in your browser. The tool never sends your file anywhere.

    Share as little as you can

    1. Column names only. Enough for an AI to write a formula.
    2. A small masked sample. 20 to 50 rows. Use it when the AI must see real-looking values.
    3. Totals. Count on your own computer and share only the totals.

    Do not share the real rows. Run the AI's formula on your own computer.

    How to use it

    1. Open a CSV or Excel file. Choose the sheet and the row with the column names.
    2. For each column, choose Mask, Remove or Keep. The card shows the result.
    3. Choose the rows you want and read the preview.
    4. Open Risk check. Fix every red item.
    5. Download the masked data. Then download the match file.

    Masking does not change the rules

    A masked copy of a secret file is still secret. Follow your organisation's rules before you share it.

    What the tool recognises

    The tool reads column names in many languages, including English, French, Spanish, German, Chinese, Japanese, Korean, Arabic and Russian. It also finds these value patterns:

    • National IDs like 123-45-6789
    • Payment card numbers, IP addresses and map coordinates
    • Private categories such as diagnosis, religion and ethnicity
    • Phone numbers like +44 20 7946 0958 or (415) 555-0100
    • Dates like 25/12/2004, 12/25/2004, 2004-12-25, 25 Dec 2004, 12 janvier 1991 or 1991年9月12日
    • Web addresses. The tool keeps the website and removes the path.
    • Money like $1,250.00 or EUR 900.50
    • Addresses with a street word or a postcode

    Check every suggestion. Other formats can look like plain text.

    The match file

    The match file links each code to the real value. With it, anyone can undo the masking.

    • Keep it on this computer. Never upload it or email it.
    • Do not open and save it in Excel. Excel changes long numbers.
    • Use the Restore names tab to put real values back.
    • Delete it when you finish.

    “Numbered” codes look like _001. The tool gives the numbers in random order. “Random” codes look like _7KQ3XZ. Both are safe. Codes ignore capital letters.

    Limits

    • The suggestions can be wrong. Check every column.
    • The tool finds names in notes only when the name is in a name column. It misses nicknames and other spellings.
    • A mix of details, such as job level, team and age group, can still point to one person. Before you share, count how many people have each mix. Merge groups that have fewer than 5 people.
    • Month names work in English, French, Spanish, Portuguese, Italian, German, Dutch and Turkish. For other languages, use number dates.
    • If letters look wrong, choose another text encoding in step 1.
    • The tool puts a “Check this column” label on text it cannot classify. This includes Chinese and Arabic text, and columns where most values are different. Read those columns yourself.
    • Excel formulas are not calculated. The tool reads the values saved in the cells.
    • Restore moves shifted dates back only in CSV and Excel files. Pasted text keeps shifted dates.
